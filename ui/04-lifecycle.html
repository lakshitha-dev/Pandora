Lifecycle States

Four screens the app needs and the earlier samples did not cover: before the first query, while ingesting, while assembling, and when an agent fails. All four are designed states — none of them is a spinner.

1 — First run

1 Empty state · corpus preloaded

The corpus is already indexed

188 chunks across 15 chapters and 135 records — ready now. Describe a situation in plain language, or start from one of these.

Ctrl K for the command palette · / to focus the question field

Why not a blank text boxA cold empty box makes the user invent a query format, and on an unfamiliar fictional corpus they will guess wrong and get a weak first answer. Four starters — one per required use case — teach the input shape and guarantee the first impression is a strong retrieval. Stating the index is already built also removes the fear that something must be uploaded first.

Why name every stage"Uploading…" tells a judge nothing. Naming the four pipeline stages, and reporting that 958 boilerplate sentences were hoisted while it runs, turns a wait into the clearest available evidence that the document processing is real. The 25-mark retrieval criterion asks for effective document processing and an appropriate chunking strategy — this is where a judge can actually see both.

Why skeletons rather than a spinnerA skeleton preserves the layout, so nothing jumps when the text lands — and the section headings are already legible, so a reader knows what is coming. More importantly, two orbs burning simultaneously while a third is already complete is the visual proof that the work is genuinely concurrent. A spinner would hide precisely the thing worth showing.

Why a partial report is a successful reportPer §2.1 rule 1, sections are independent: one failing must never blank the others. Showing a handled timeout builds more credibility with a judge than hiding it, because it proves the timeout logic exists rather than merely being described in a slide. The confidence meter states why it dropped, which is the difference between "this answer is weak" and "this report is incomplete" — those need different responses from a guardian.
